# Build a Localhost Web App for YOLO Weld Quality Detection

## Role

Act as a senior full-stack developer and computer-vision engineer.

I already have a working YOLO-based Python application for detecting **good welds and bad welds**. I want you to convert/integrate my existing YOLO detection code into a professional web application that runs completely on my local machine.

Do **not** replace my YOLO model or detection logic unnecessarily. First inspect the existing project files and understand how my current YOLO inference code works, then integrate it into the web application.

---

## Project Goal

Build a web application for **weld quality inspection using YOLO**.

The application should allow the user to detect whether a weld is:

* **Good Weld**
* **Bad Weld**

The user should be able to perform detection in two ways:

1. **Upload an image**
2. **Open the webcam and perform real-time detection**

The application must run locally on **localhost**.

# 10. Backend API

Create clean API endpoints.

For example:

```text
GET  /health
POST /predict
```

`/health` should return whether the backend and YOLO model are ready.

`/predict` should:

1. Receive an uploaded image.
2. Run YOLO inference.
3. Process detections.
4. Return structured JSON.
5. Return an annotated image or a way for the frontend to display it.

Example response structure:

```json
{
  "success": true,
  "detections": [
    {
      "class_id": 0,
      "class_name": "Good Weld",
      "confidence": 0.94,
      "bbox": {
        "x1": 100,
        "y1": 80,
        "x2": 300,
        "y2": 250
      }
    }
  ],
  "overall_result": "Good Weld"
}
```

Adapt this structure to the actual classes and output produced by my existing model.

# 17. Webcam Performance

Do not unnecessarily send every raw webcam frame to the backend if that causes performance problems.

Design the webcam inference efficiently.

Possible approach:

* Capture webcam frames in the browser.
* Resize frames before sending them.
* Run inference at a reasonable interval.
* Avoid overlapping requests.
* Display the most recent detection result.

The goal is a smooth local demo rather than maximum FPS.

If the existing YOLO/OpenCV application already performs webcam inference locally in Python, consider whether it is better to keep inference in Python and stream annotated frames to the frontend.

Choose the simplest reliable architecture after inspecting the existing code.
