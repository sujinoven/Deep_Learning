How It Works

Understanding the 4-stage neural image reconstruction pipeline.

01

INPUT

The digit is captured, converted to grayscale, and normalized to a 28×28 float array [0.0, 1.0].

02

CORRUPT

Controlled Gaussian noise is added to simulate sensor noise, degradation, or pixel corruption.

03

ENCODE

Convolutional layers compress the 28×28 input into a compact 7×7×8 latent representation feature map.

04

RECONSTRUCT

Transposed/UpSampling decoder layers filter out noise and reconstruct clean digit strokes with Sigmoid activation.
